# ArtiChat 0.1.7

0.1.7 新增按消息控制的五档推理强度，并补齐模型级配置与请求映射。

## 更新内容

- **模型级推理控制**：管理员可为模型启用推理强度，并明确选择 GPT / Codex 或 Claude 推理类型；未启用的模型继续使用原有参数行为。
- **五档滑块**：提供 Low、Medium、High、Extra（GPT 显示 Extra High）和 Max 五档，Max 为最高档。支持鼠标拖动、键盘操作、移动端底部面板和 reduced-motion。
- **消息级快照**：发送或排队时记录模型与推理档位；生成期间调整滑块只影响下一条消息，队列按原顺序逐条发送。
- **响应元数据**：用户消息与助手响应保留实际推理档位和推理类型；重新生成使用当前档位，继续生成保留原响应档位。
- **后端校验与映射**：浏览器只发送内部档位，服务端根据已保存的模型类型校验并映射为上游 `low`、`medium`、`high`、`xhigh` 或 `max`；Responses 请求使用嵌套的 `reasoning.effort`。

## 兼容性与限制

- 多模型对话不显示新的推理滑块。
- 未启用新控制的模型保留旧版自由文本 `reasoning_effort` 设置。
- 原生 Anthropic `/v1/messages` 请求仍不在本版本范围内，当前链路继续使用 Responses 转换。
