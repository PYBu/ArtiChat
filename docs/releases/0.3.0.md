# ArtiChat 0.3.0

Dreammaker ProEdition.

## Highlights

- Added image/video generation integration points with provider-aware jobs, terminal status handling, inline playback, and media usage accounting.
- Added Asset Center for uploaded and generated files, including filtering, search, preview, download, revocable share links, and ownership checks.
- Added automatic memory review with silent background maintenance, duplicate suppression, bounded operations, sensitive-content filtering, and user opt-out.
- Reworked Chatpoint reservation and settlement for text, image, and video usage, including failure release and auditable usage records.
- Added configurable tool and operation status rendering. Internal memory-maintenance calls remain invisible while ordinary tool details stay visible.
- Added login-time access restrictions: country-level GeoIP rules, exact IP/CIDR blacklist rules, administrator bypass, registration blocking, stable restricted pages, account login-IP display, and searchable seven-day login history.
- Added the Operations `Access Restrictions` page and admin-only configuration/history APIs.
- Added `maxminddb` support for an offline country database. The database is supplied separately and is never committed to the repository.

## Upgrade Notes

- ArtiChat 0.3.0 uses additive database migrations and supports direct upgrades from the existing 0.1.7 and 0.2.x data layouts. Back up the data directory before upgrading and verify `/ready` after restart.
- The default GeoIP path is `DATA_DIR/geoip/dbip-country-lite.mmdb`. Country restrictions fail open when no database is present; IP/CIDR rules continue to work. Install a current, licensed country MMDB and follow its attribution terms.
- Access restrictions apply only when issuing a new login or registration session. Existing sessions are not revoked. Administrators bypass the policy based on their persisted server-side role.
- The release image is published as `ghcr.io/pybu/artichat:0.3.0` and `ghcr.io/pybu/artichat:latest` by the release workflow.
