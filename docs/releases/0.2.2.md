# ArtiChat 0.2.2

ArtiChat 0.2.2 在 0.2.1 基础上完成体验稳定性、计费流程和运营工具更新，并继续支持从已发布的 0.1.7 直接升级。

## 主要更新

- 邮箱验证码改为持久化异步投递队列：请求不再等待 SMTP 完成，支持租约、重试、退避和重启恢复；验证码内容保持加密存储。
- 聊天模型响应与 Chatpoint 结算解耦：模型响应完成后即可继续下一次对话，结算通过持久化任务异步完成，并保留幂等、限额和不足余额保护。
- 额度环状入口统一打开权威用量页面，额度不足提示统一为“额度不足支撑下次对话。”。
- 个人订阅中心、订阅、账单用量和兑换码页面统一中文标题、左对齐布局和稳定滚动区域，修复切换页面时的横向抖动与 URL tab 状态竞争。
- 运营管理工具卡片改为紧凑布局，新增插件中心 UI 壳子。ACPlugin 当前显示未连接；邮箱助手仅显示开发中且不可启用。
- 记录 ACPlugin 后续插件规范：Manifest、签名信任、声明式权限、个人上传隔离、沙箱、审计和回滚规则。当前版本不连接目录、不执行插件、不持久化上传文件。

## 验证

- 前端 Vitest：16 个测试文件、37 个测试通过。
- Vite 生产构建：SSR 1,733 个模块，客户端 6,460 个模块通过；保留仓库已有的 Svelte、chunk size 和 Pyodide externalization 警告。
- 私有候选实例 `3002` 的 `/health`、`/ready` 和 `/api/version` 均返回 200；生产 `3000` 未被替换。

## 升级提示

升级前请停止写入并备份 `artichat_data`。0.1.7 不可直接连接已经迁移到 0.2.2 的数据卷；回滚时必须恢复到独立的升级前数据卷。
