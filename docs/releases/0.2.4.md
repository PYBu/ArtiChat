# ArtiChat 0.2.4

## Fixed

- Reconnected the Admin Settings -> Update panel to the official `PYBu/ArtiChat` release source by default.
- Made disabled checks, missing repository configuration, and GitHub request failures visible instead of reporting the running version as latest.
- Added `update_available` and `error` fields to the legacy version-update response for compatible clients.
- Made the production Compose and AWS/1Panel deployment runner derive `ghcr.io/pybu/artichat` when no image repository override is supplied.

## Verification

- Update service and router tests: 23 passed.
- Platform/runtime compatibility tests: 13 passed.
- Frontend Vitest: 16 files, 37 tests passed.
- Release-version, update-system, subscription, and branding guards passed.

This release requires the running installation to receive the new image once. Existing 0.2.2 and 0.2.3 containers cannot repair their own updater code; back up `artichat_data` and verify `/ready` after the container starts.
